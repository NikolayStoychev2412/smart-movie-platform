# MovieMaze – Уеб платформа за филми

MovieMaze е уеб приложение за управление на филмов каталог, което използва изкуствен интелект за семантично търсене и персонализирани препоръки. Платформата поддържа двуезичност (български и английски) и предоставя модерна среда за потребители и администратори.

---

## Основни функционалности

- AI семантично търсене (на български и английски език)
- Персонализирани препоръки на база предпочитания
- Анализ на ревюта (sentiment analysis)
- Потребителски профили и статистики
- Watchlist и любими филми (favourites)
- Административен панел
- JWT базирана автентикация
- Ограничаване на заявки (rate limiting)

---

## Технологии

### Back-end
- FastAPI
- PostgreSQL
- SQLAlchemy
- FAISS (векторно търсене)
- sentence-transformers
- HuggingFace Transformers
- JWT (python-jose)

### Front-end
- React 18 + TypeScript
- Vite
- Tailwind CSS
- react-i18next

### Инфраструктура
- Docker & Docker Compose
- Caddy (reverse proxy)
- Vercel (front-end хостинг)

## Описание на ролите

### Администратор
Администраторът има достъп до:
- административен панел;
- управление на потребители;
- промяна на роли;
- преглед, редактиране и изтриване на филми;
- достъп до всички потребителски функционалности;
- преглед на статистики;
- преглед на одит логове.

### Потребител
Потребителят може да:
- разглежда филмовия каталог;
- търси филми (включително AI търсене);
- преглежда детайлна информация за филми;
- добавя филми към watchlist;
- добавя филми към любими;
- пише ревюта;
- получава персонализирани препоръки;
- преглежда профил и статистики.
